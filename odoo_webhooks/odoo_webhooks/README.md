# 🔗 Webhook Integration for Odoo

Envía datos en tiempo real desde Odoo a cualquier sistema externo mediante Webhooks. Ideal para conectar con APIs, automatizar flujos con herramientas como Zapier, Make, o integrar con sistemas externos (CRMs, ERPs, etc.).

### 🎯 Compatible con los siguientes modelos:
- Ventas (`sale.order`)
- Compras (`purchase.order`)
- Facturas (`account.move`)
- Albaranes (`stock.picking`)
- Productos (`product.product`)
- Contactos (`res.partner`)

---

## 🧩 Características Principales

✅ Configura múltiples Webhooks desde una vista central.  
✅ Selecciona qué campos enviar y el formato JSON generado.  
✅ Botón de envío manual por registro.  
✅ Compatible con múltiples endpoints.  
✅ Soporte para campos relacionales y fechas.  
✅ Timeout configurable.  

---

## ⚙️ Instalación

1. Descarga el archivo `.zip` desde apps.odoo.com.
2. Extrae la carpeta `webhook_integration/` en tu carpeta de addons.
3. Reinicia el servidor de Odoo.
4. Ve a **Apps > Actualizar Lista**.
5. Busca "**Webhook Integration**" e instálalo.
